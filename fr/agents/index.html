Coulisses — Workflow CLI en arrière-plan

Le bulletin PDF est la sortie visible — mais avant la décision finale BUY / HOLD / SELL, les 7 agents IA exécutent un cycle complet de recherche en arrière-plan. Avec python run_daily.py --ticker SNTS.sn --date 2026-03-28 --debug, TradingAgents affiche chaque étape dans le terminal : initialisation du pipeline, appels d'outils de données, raisonnement structuré des agents, débat contradictoire, puis génération PDF + JSON. Voici ce workflow capturé en direct (SNTS.sn — Sonatel, 2026-03-28).

Étape 1

Initialisation du pipeline & lancement de l'analyse

Commande : run_daily.py --ticker SNTS.sn --date 2026-03-28 TradingAgentsGraph initialisé avec le vendor 'brvm'

Ce que vous voyez : BAQA démarre, charge la config BRVM, initialise la couche d'orchestration LangGraph et entre en mode ticker unique pour SNTS.sn.
Pourquoi c'est important : Point d'entrée unique — une commande CLI déclenche l'ensemble du pipeline multi-agents.

Étape 2

Récupération des données — outil get_stock_data

Agent : Analyste Technique Source : daily_quotes via brvm_supabase.py 22 séances · FCFA · BRVM/UEMOA

Ce que vous voyez : L'agent Analyste Technique invoque get_stock_data et reçoit l'historique OHLCV réel — cours, volumes en titres et en XOF, variation quotidienne %.
Pourquoi c'est important : Les agents ne hallucinent pas les prix — ils raisonnent sur des données Supabase via le vendor 'brvm'.

Étape 3

Indicateurs techniques — outil get_indicators

Agent : Analyste Technique Indicateurs : ATR, clôtures, volumes, variations

Ce que vous voyez : Un second appel d'outil retourne les indicateurs calculés (ATR, clôture, volume, variation) formatés pour le LLM.
Pourquoi c'est important : Illustre le pattern tool-use — les agents appellent des fonctions de données spécialisées, puis interprètent les résultats.

Étape 4

Raisonnement agent — Conclusion fondamentale

Agent : Analyste Fondamental Champs : PER, DNPA, rendement, historique dividende Sortie : FINAL TRANSACTION PROPOSAL

Ce que vous voyez : L'Analyste Fondamental synthétise les données BOC en conclusion structurée — tableau (PER 6,87, DNPA 1 655 FCFA, rendement 5,83 %) et proposition de transaction initiale.
Pourquoi c'est important : Chaque agent produit un raisonnement auditable en français — alimentant le débat Bull vs Bear avant la décision finale du Trader.

Étape 5

Décision finale & génération PDF

Agent 7 : Trader + Risk Manager Décision : SELL (run debug) Sorties : BRVM_Bulletin_*.pdf + BRVM_*.json

Ce que vous voyez : Après le cycle complet (4 analystes → débat Haussier/Baissier → Trader), le pipeline logue la décision finale (SELL dans ce run debug), puis report_generator.py assemble le bulletin PDF et sauvegarde l'état JSON brut.
Pourquoi c'est important : Boucle complète — d'une commande CLI à une recommandation actionnable et un PDF client, en moins de 3 minutes.

Agent 1 — Analyste Fondamental

📊 Évaluation de la santé financière

Rôle : Évaluer si une action BRVM est fondamentalement saine pour l'investissement
  • PER actuel vs PER sectoriel
  • DNPA — Dividende Net Par Action en FCFA
  • Rendement net et compartiment (Prestige / Principal)
  • Carnet d'ordres et liquidité réelle du titre
Source : Supabase boc_daily, boc_order_book
Sortie JSON : fundamentals_report
Section PDF : Analyse Fondamentale
Agent 2 — Analyste Technique

📈 Analyse des signaux prix & volumes

Rôle : Détecter tendances, momentum et signaux techniques
  • Historique OHLCV quotidien
  • Tendances sur 30, 60 et 90 jours
  • MACD, RSI, moyennes mobiles (50 SMA, 200 SMA)
  • Bandes de Bollinger pour signaux de retournement
  • Beta et volatilité relative au marché BRVM
Source : daily_quotes via pipeline Sikafinance
Sortie JSON : market_report
Agent 3 — Analyste Actualités

📰 Interprétation macro & actualités

Rôle : Relier les événements externes à la thèse d'investissement
  • Actualités boursières liées à la société
  • Contexte macro UEMOA : PER marché, prime de risque
  • Performance des indices sectoriels
  • Palmarès du jour : plus fortes hausses et baisses
Source : news, boc_market_summary, palmares
Sortie JSON : news_report
Agent 4 — Analyste Sentiment

📡 Humeur du marché & signaux d'alerte

Rôle : Mesurer le sentiment investisseur et détecter les anomalies
  • Tendance sentiment des actualités récentes
  • Performance relative vs indice BRVM
  • Anomalies de volumes, écarts de cours inhabituels
Sortie JSON : sentiment_report
Agents 5 & 6 — Chercheur Haussier & Baissier

⚖️ Débat contradictoire d'investissement

Rôle : Forcer une analyse équilibrée par contradiction structurée
  • Haussier : indicateurs positifs, croissance, sous-évaluation
  • Baissier : risques, surévaluation, faible liquidité BRVM, macro défavorable
Sortie JSON : investment_plan
Section PDF : Plan d'Investissement (Debat Bull vs Bear)
Agent 7 — Trader + Risk Manager

🎯 Recommandation finale & gestion du risque

Rôle : Synthétiser toute l'analyse en décision actionnable
  • Décision finale : BUY / HOLD / SELL
  • Niveau de confiance
  • Plan d'action détaillé avec justification
  • Risques BRVM : fixing quotidien, contraintes de liquidité
Sortie JSON : final_trade_decision
PDF : Encadré décision coloré + section Décision Finale
